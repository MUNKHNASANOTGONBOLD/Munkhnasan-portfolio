# Analytics portfolio

This repository contains the source for my [analytics portfolio](https://munkhnasan-portfolio.vercel.app/). I use the site to share projects in SQL, Python, Power BI, and Tableau alongside my work in finance, budgeting, and reporting.

The Next.js application lives in `app/` and site assets are in `public/`. [CONTENT_INVENTORY.md](CONTENT_INVENTORY.md) lists the site content. [MIGRATION_CHECKLIST.md](MIGRATION_CHECKLIST.md) records the site migration checks.
