# Mason Otgonbold — Portfolio

Next.js 14 (App Router) + Tailwind CSS. Single-page "financial ledger" themed portfolio.

## Run locally
```
npm install
npm run dev
```

## Deploy
Push this repo to GitHub, then import it at vercel.com/new.
No environment variables are required.

## Customize
- Content lives in `app/page.tsx` (`NAV`, `METRICS`, `LEDGER`, `SKILLS`, `VENTURES` arrays)
- Colors/fonts: `tailwind.config.ts`
- Update the email + LinkedIn placeholder links in the Contact section
